### 📋 Task Management & WhatsApp Follow-Up System · *Frammer AI*

A role-based task management platform for HR, Managers, and Employees covering task assignment, tracking, status management, and follow-ups. It syncs recent task activity from Asana (read-only) and shows employee-wise task data with pagination and loading states.
